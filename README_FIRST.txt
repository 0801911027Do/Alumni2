🚀 QUICK SETUP (10 MINUTES)

FOR IMPATIENT PEOPLE:

   1. Open "src/alumni.html" in browser
      → See login page

   2. Deploy Google Apps Script:
      a) Go to script.google.com
      b) Create new project
      c) Copy code from "src/AppsScript_Updated.gs"
      d) Click Deploy → New deployment → Web app
      e) Copy the URL it gives you

   3. Update API URL:
      a) Open "src/alumni.js" in text editor
      b) Find line: const API_URL = ...
      c) Replace with URL from step 2e
      d) Save file

   4. Refresh browser, login with:
      Username: admin
      Password: admin123

   5. Click "นำเข้าข้อมูล" and upload "sample_data.xlsx"

   6. View dashboard - Done! 🎉

For detailed guide: See QUICK_START.md
